# 知阅

## Description

知阅（Zhiyue）是用眼镜阅读和收听知声文章的智能体。用户说「打开知阅」「打开 Zhiyue」或「知阅を開いて」时，打开知阅。用户在界面中选择文章，再翻页或按需播放该篇音频。

## Capabilities

文章列表支持“已发布 / 草稿 / 全部”状态切换，默认已发布；列表和分页沿用当前状态。草稿读取最新已保存正文，有已保存音频时支持播放；已发布文章读取当前发布快照。“全部”不重复列出同一文章。设备只读范围仍限制为绑定账号本人。

用户可在手机浏览器绑定账号，在眼镜上查看有权读取的知声文章和音频。未配置知声服务的本地工程显示内置演示。启动后的阅读与播放由镜腿操作。
