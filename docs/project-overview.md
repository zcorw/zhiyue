# 知阅项目概览

## 定位

面向 Rokid 场景的独立沉浸式浏览项目，采用文字主导的极简页面。

## 已确认

名称为「知阅」。独立页面、文字为主体、少量图标用于状态与区域标识，是用户明确要求。用户希望项目与现有知声等系统独立管理，在本项目新会话中开展后续工作。

对话、项目文档和代码注释均使用中文。

- 目标设备为 Rokid スマートAIグラス 国际版，眼镜系统 1.28.016。手机可以在口袋里提供网络，选文、翻页和返回在眼镜上完成，优先使用镜腿触控或眼镜按键。
- 首版覆盖用户有权读取的全部知声已发布文章，支持播放文章音频。权限建立与媒体获取方式待定。
- 音频在正文内播放或暂停，播放时可用镜腿手动翻页，返回列表时停止播放。
- 允许先用眼镜端语音启动。真机排版验收覆盖简体中文、日文及两者混排。
- 用户已验证虚构演示在实机上的操作流程。知声接入采用手机确认配对码，首轮以每个眼镜应用安装一个当前账号为设计基线。
- 2026-11-12 用户确认：初版不要求硬件加密或硬件级安全存储；必须实现自动续期，让眼镜一次绑定后长期读取知声文章。绑定不设强制重新配对总期限、不因闲置失效，再次联网后自动续期恢复。
- 已确认账号与升级规则：改知声密码撤销该账号眼镜授权；普通知声网页退出保留眼镜绑定。新版本上线时有效旧绑定自动升级，已过期旧绑定重新配对一次。本地客户端已接入升级和续期，真实账号事件联调待进行；本轮未更新知序状态。
- 2026-11-12 本机知声旧检出不支持续期；2026-11-13 线上响应和远程 `main` 已确认采用含确认、刷新及升级的新设备协议。设备授权继续独立于 MCP 刷新令牌，后者不适用于眼镜。知声后端未在本轮修改，完整线上联调仍待进行。
