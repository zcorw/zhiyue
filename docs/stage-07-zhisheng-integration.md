# 知声账号绑定与只读接入

知声接入已上线。用户已在眼镜上验证账号绑定、正文阅读和 MP3 播放。隔离环境还验证了两账户数据隔离和解绑。知阅 1.0.8 已同步真机调试包，音频内存缓存仍待真机复测。

## 用户操作

1. 在眼镜上选择「绑定知声账号」，查看验证地址和一次性配对码。
2. 手机上打开知声「账户设置 → 连接知阅」，使用想要绑定的账号登录，核对网页上显示的账号，再输入眼镜上的码并确认。
3. 眼镜领取只读凭据后进入该账号的全部已发布文章。点击有音频的正文时才请求播放地址。
4. 换账号时在眼镜解除当前绑定，再用另一个知声账号重新配对。也可以在知声「连接知阅」页面撤销某次设备授权。

用户提供的 CMS 地址为 `https://interview.zcorw.xyz`。验证页路径为 `/connections/zhiyue`。配置项保存在 `aiui/data/zhisheng-config.js`，当前眼镜工程已启用真实模式。

## 多账户边界

知声从已登录的网页会话决定 `accountId`，网页请求中的预期账号 ID 只用于发现浏览器切换账号。客户端每个安装保留一个当前绑定，服务端为同一知声账号的不同设备签发彼此独立的 `bindingId`。列表、正文、音频都从有效凭据解析账号和权限。未来增加账号选择时，可用 `accountId` 和 `bindingId` 分隔各会话。

本轮用 5 分钟配对码和最长 24 小时的设备只读授权。眼镜端按应用保存可撤销的绑定及到期时间，私人文章和音频不持久化。绑定过期后重新在手机确认。重装或清空眼镜存储后，旧授权可在网页撤销，最长在 24 小时内到期。若后续延长登录时间，先核实真机密钥存储并补充续期与重放处理。[设备授权规范](https://www.rfc-editor.org/rfc/rfc8628.html)

## 接口与媒体

- `/v1/zhiyue/device/*` 负责申请、单次领取、解除设备绑定。领取使用与人用短码独立的高熵设备码，知声只保存凭据哈希。
- `/v1/zhiyue/account/*` 使用知声已有的同源网页会话和 CSRF 防护，允许账号本人确认或撤销。
- `/v1/zhiyue/read/*` 用设备 Bearer 按页读取当前发布，打开正文时取详情。使用知声已有的账号与发布版本查询边界。
- 播放地址使用独立的不透明短票，最长 150 秒，绑定账号、设备授权和发布版本。每次读取和字节范围请求都重新校验，解绑后阻止后续读取。播放地址按私有资源处理，生产代理须避免把票据路径写入访问日志。

- 知阅按当前设备绑定和发布版本在内存中保留最近使用的音频，最多 3 篇、共 4 MiB。命中后仍向知声申请短票确认权限，省去媒体下载。切换绑定、解绑和授权失效时清理缓存。
