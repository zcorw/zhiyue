# Stage 2 · 阅读与播放流程

进行中。已确认允许语音启动，进入知阅后的阅读和播放操作在眼镜上完成。首版覆盖所有授权已发布文章。

## 已确认的播放规则

- 在正文内播放或暂停文章音频。播放期间仍可用镜腿手动前后翻页。
- 从正文返回文章列表时，立即停止当前音频。

[虚构数据演示](demo.md)已实现这两项。演示首屏直接显示按发布日期倒序排列的全部文章，正式版的首屏入口仍待确认。

## 主流程草案

语音打开知阅 → 浏览文章 → 镜腿确认进入正文 → 滑动翻页 → 按需播放这篇文章的音频 → 返回列表或退出。

| 待确认 | 方案 |
| --- | --- |
| 入口 | 直接进入全部文章，或先选择分类并提供全部文章入口 |

## 异常与退出草案

| 情境 | 候选行为 |
| --- | --- |
| 列表加载中或没有可读文章 | 显示简短状态，保留返回或退出操作 |
| 内容加载失败或授权失效 | 说明状态，保留重试与返回。授权恢复方式留待接口阶段确定 |
| 无音频或音频加载失败 | 保持正文可读。有音频但加载失败时提供重试 |
| 用户退出知阅 | 停止播放并清理当前音频请求 |

播放以同一发布版本的音频资产为候选。官方 `AudioPlayer` 文档描述了网络 URL、文件缓冲和播放控制能力。目标固件在手机锁屏时的受保护音频传输、解码与输出仍需验证。 [AudioPlayer 官方文档](https://github.com/yodaos-project/AIUI/blob/main/documentation/3-api/media/audio-player.en-US.md)
