- 对话、项目文档和代码注释均使用中文。见[语言约定](stage-setup-language.md)。
- 首版以 Rokid スマートAIグラス 国际版和系统 1.28.016 为目标。手机可以在后台联网，阅读操作由眼镜自身触控或按键完成。真机测试记录完整的系统与 Hi Rokid 版本，并区分安装和日常阅读。

- 知声接入使用手机网页确认短码。设备只读授权按账号和绑定分别标识，可由账号本人撤销，验收覆盖多账号数据隔离。
- 2026-11-12 用户确认初版不以硬件加密或硬件级安全存储为前提，自动续期必须实现；绑定无强制重新配对总期限、不因闲置失效，应用重启或再次联网后自动续期恢复。短期读取凭据可设置技术有效期和轮换，但不得因此引入绑定总期限或闲置失效，也不要求应用关闭或眼镜关机期间持续后台续期。
- 修改知声密码撤销该账号全部眼镜授权；普通退出知声网页保留眼镜绑定。新版本上线时有效旧绑定自动升级，无需重新配对；已过期旧绑定需重新配对一次。已撤销或停用账号的授权不得通过升级或续期恢复。
- 保留只读权限、账号隔离、解绑和网页撤销，不保存账号密码或长期管理员凭据。本地已按知声设备协议保存最长 24 小时的访问凭据和独立设备刷新凭据，接入自动续期及失败恢复；真实账号事件和真机验收待进行。本轮未修改知序需求状态。
- 自动续期需知声设备接口配套，不能用其 MCP 刷新令牌代替设备授权。2026-11-12 本机旧检出尚不支持设备续期，后端需求为 `2ecc0102-a81d-4b65-83f3-21cd851b809f`；2026-11-13 线上响应及远程 `main` 已采用新版设备协议，双方按对应契约联调。源码检查不代表线上完整续期或真机验收。
- 正文内支持播放和暂停。播放期间镜腿仍可手动翻页，返回列表时停止当前音频。
- 首版允许眼镜端语音启动。真机排版验收覆盖简体中文、日文及两者混排。
- 演示使用沉浸式 AIUI，电脑预览使用原生 HTML、CSS、JavaScript 与 Node.js 本地服务。二者共用 `aiui/data/articles.js` 和 `aiui/assets/`。正式集成的依赖、接口和交付仍按阶段确认。
- 文件采用 UTF-8；已确认决定与待确认方案分开记录。
