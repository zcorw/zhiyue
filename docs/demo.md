# 知阅虚构数据演示

演示含六篇虚构文章，覆盖简体中文、日文和两者混排。列表按发布日期从新到旧，正文支持前后翻页。有音频时可在正文播放、暂停和继续，返回列表时停止。两段朗读由本机语音合成生成，随工程打包为 Ogg/Opus。

## 电脑预览

用 Node.js 22 在项目根目录运行 `node serve-preview.mjs`，打开 [本机预览](http://127.0.0.1:4178/preview/)。方向键选文或翻页，Enter 确认或控制播放，Esc 返回，也可以直接点击按钮。进入「第一班电车之前」或「窗边的一小格光」可试播。

## Rokid 工程

在 AIUI Studio Global 选择本地导入，并选择项目内的 `aiui/` 目录。打开交互模拟，验证列表选择、正文分页、播放和返回。真机步骤按 Global 指南打包 AIX，并通过 Hi Rokid 的开发者入口更新眼镜资源包，再试说「Hi Rokid，打开知阅」。 [AIUI Studio Global 快速入门](https://js.rokid.com/AIUI/guide/quickstart/quickstart?lang=en-US&version=latest)

真机优先核对 1.28.016 上的启动、镜腿方向、确认及返回映射、中日文混排和音频输出。演示使用内置音频，正式首版的手机锁屏联网和受保护媒体传输另列验收。
